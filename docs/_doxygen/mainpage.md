# PCA9555 / PCAL9555A Driver API reference {#mainpage}

The classes, members and registers of the HardFOC driver for the NXP PCA9555 and PCAL9555A 16-bit I2C I/O
expanders, generated from the headers.

Start with pcal95555::PCAL95555, the driver, and pcal95555::I2cInterface, the interface your platform port
implements. The register map is Pcal95555Reg; the chip variants are pcal95555::ChipVariant; the error flags are
Error.

The guides, with examples that compile, are on the documentation site: <a href="../">PCA9555 / PCAL9555A Driver
documentation</a>.
